# Studio Matsya

Static portfolio website for Studio Matsya, the Jaipur-based art and design studio founded by Satyam Sharma.

## Publish

The site is configured for GitHub Pages at <https://naruto0o23.github.io/studiomatsya/>. In the repository settings, choose **Pages → Deploy from a branch**, then select `main` and `/ (root)`.

## SEO and site URL

The canonical URL, social-sharing metadata and structured business data are in `index.html`; the sitemap is `sitemap.xml`. If the repository URL or domain changes, update the URL in both files. Submit the sitemap URL to Google Search Console after deployment.

Service copy and project details are maintained in `index.html` and `script.js`, respectively.
