# Studio Matsya — Portfolio Website

A static, GitHub Pages-ready portfolio site built from the visual language and project material in the Studio Matsya pitch deck.

## What is included

- Responsive editorial portfolio website
- Cream / charcoal / Studio Matsya red visual system
- Oversized condensed headlines and thin red rules
- Hero artwork, founder portrait and contact artwork from the deck
- Filterable portfolio: Murals / Paintings / Objects + Space
- Project lightbox with description, location, size and duration
- Original pitch deck PDF in `assets/studio-matsya-pitch-deck.pdf`
- No build step and no framework — just HTML, CSS and JavaScript

## GitHub Pages

1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save. GitHub Pages will publish `index.html`.

## Customize

- Edit project content in `script.js`.
- Edit colours, typography and layout in `styles.css`.
- Replace any image in `assets/images/` with a higher-resolution version while keeping the same filename.
